Security analysis methodology

How PhishShield interprets URL indicators

Machine learning

Trained classifier estimates phishing probability using URL features.

Rule-based indicators

Transparent checks identify IP hosts, suspicious terms, brand mismatch, shorteners and unusual URL structure.

Hybrid score

40% ML probability and 60% rule score. Thresholds: 0–29 low, 30–59 suspicious, 60–100 high risk.

Privacy and safety

Submitted links are not opened, fetched, crawled or followed. URL text only.

Important limitation

HTTPS, familiar brand names or a low score do not prove a website is safe. False positives and false negatives can occur.
